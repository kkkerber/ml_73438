# Problem definition

The task is to predict whether a person's annual income is greater than $50,000 using the Adult dataset. The experiment uses the exact dataset requested in the lab: `fetch_openml(name="adult", version=2, as_frame=True)`. Each of the 48,842 records contains 14 input features and one income label. The inputs include six numerical features, such as age, weekly working hours and capital gains, and eight categorical features, such as education and occupation. The OpenML target is named `class`; the pipeline exposes it as `income`. The positive class is `>50K` and the other class is `<=50K`.

This is a binary classification problem. Logistic Regression provides the baseline. Model quality is measured using accuracy and F1 for the positive class. Accuracy describes the overall share of correct predictions, while F1 combines precision and recall for the higher-income class. Reporting both is useful because the classes have different frequencies. The experiment compares a model using the original inputs with a model that also receives `capital_net` and `hours_per_age`. The model parameters and test split remain fixed during this comparison.

The main constraints are reproducibility and prevention of data leakage. Data are split into 70% training and 30% testing with stratification and a fixed random seed before cleaning. Imputation values, clipping thresholds, scaling parameters and encoding categories are learned only from training data. Exact duplicates are removed from training only. Test rows are retained and transformed using the fitted training rules. Raw data are preserved, validation problems are reported, and missing labels or schema violations stop training rather than silently removing records.

The expected deliverable is a pipeline that runs with one command and saves validation evidence, model metrics, a fitted preprocessor, a label-quality audit, the processed-data SHA256 hash and the effective configuration. This is an educational experiment on historical data; its scores alone do not establish suitability for decisions about individual people.
